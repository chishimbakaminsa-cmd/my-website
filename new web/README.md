# Colleen Kamisa — Personal Portfolio Website

## About the Project

This project is a personal portfolio website created by **Colleen Kamisa**, a student studying Web Development at **Information and Communications University (ICU)**.

The website was developed as part of an **HTML Website Development assignment** to demonstrate the use of HTML5 and semantic HTML elements.

## Features

The portfolio website includes:

* **About Me** section introducing the developer
* **Skills** section showcasing technical skills
* **Skill Progress** indicators for HTML and CSS
* **Language Proficiency** table
* **Projects** section displaying current and planned projects
* **Project details** using the HTML `<details>` and `<summary>` elements
* **Feedback Form** with:

  * Name field
  * Email field
  * Message textarea
  * Rating selection
  * Subscription checkbox
  * Submit button
* **Contact** section with email and location information
* **Back to Top** navigation link

## Technologies Used

The website was built using:

* **HTML5**
* Semantic HTML elements
* HTML forms
* HTML tables
* HTML5 `<progress>` elements
* HTML5 `<details>` and `<summary>` elements

No external frameworks or libraries are currently used.

## Semantic HTML

The project makes use of several semantic HTML5 elements, including:

```text
<header>
<nav>
<main>
<section>
<article>
<footer>
<address>
```

These elements help organize the webpage into meaningful sections and improve readability, accessibility, and maintainability.
